## 📊 Ключевые находки

### 🔴 Критические (P0)
1. **Самопальное хеширование паролей** — SHA256 вместо bcrypt
2. **Публичные endpoints для паролей** — GET /users/:id/get_password
3. **Дублирование auth логики** — 85% кода повторяется между сервисами
4. **Weak session management** — Thread.current + Redis + Cookies одновременно
5. **OpenStruct вместо моделей** — нет type safety

### 🟠 Серьёзные (P1)
1. **24 консюмера без единого паттерна**
2. **Нет транзакций** в критических операциях
3. **Sync HTTP calls** без timeout
4. **Разные форматы ошибок** в API

### 🟡 Умеренные (P2)
1. **User модель — 146 строк** — слишком много ответственностей
2. **N+1 запросы** в контроллерах
3. **Нет индексов** на часто используемые поля
4. **Emoji в логах** — плохо для парсинга

## 📈 Статистика проекта

- **Сервисов:** 4 (auth, web, minecraft, mailer) + frontend
- **Языков:** Ruby (Rails 8.1.3), TypeScript/React
- **Стек:** Kafka, Redis, ClickHouse, SQLite/PostgreSQL
- **Авторизация:** Devise + JWT + 2FA + OAuth
- **OAuth провайдеров:** 4 (Discord, Twitch, TikTok, Google)
